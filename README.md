# GothRTOS

GothRTOS is a small, statically allocated microkernel written in C11 with a lua-oriented userspace execution.

> The name just started as a joke and I was like "Huh, why not?" and now there it is
> It is still not a bootable kernel, for now just runs in UM (usermode/hosted in another kernel), but I aim at porting it to legacy ARM devices (ARM7-ARMv7) and also AVR devices.
